# Project instructions

## Archive before every change

Before making any change to this project, create a complete snapshot of the current project folder at:

`E:\Programming\Music Player\Workbench\Archive\Archive G\G<next-number>\Source`

Use the next available number after the existing `G1`, `G2`, `G3`, etc. snapshots. Copy the entire current project folder, including all files and subfolders, before editing anything. Preserve the original project and never overwrite an existing archive snapshot. After the snapshot is verified, make the requested change.

If the archive location is unavailable or the next snapshot already exists, stop before editing and report the problem.
