# Security

Xplayer is a pre-release Windows app. Report security problems privately, not as public issues.

Use GitHub's private reporting: the repository's **Security** tab, then **Report a vulnerability** (https://github.com/ExhataQ/Xplayer/security/advisories/new). Include the version (Settings > Data > About), what you did and what happened. Leave out your music library, file paths and API keys.

Expect a first answer within about a week. This is a one-person project, so a fix may take longer; you will be told where it stands. Only the latest release is supported.

Not vulnerabilities: the builds are unsigned, so SmartScreen warns on first run, and updates are manual.
