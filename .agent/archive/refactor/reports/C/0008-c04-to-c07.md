## MUST be applied together with one line of Agent A's
`src/js/core/legacy.js`, `data-stop` handling: `event.stopPropagation()` must become `event.stopImmediatePropagation()`.
Why: an inline `event.stopPropagation()` on a button hid the click from every listener on `document` (tooltip, selection clearing, context-menu close). `data-stop` runs at `document`, so those listeners still ran, and clicking e.g. the "play next" button with songs selected cleared the selection. With the one-line change all 73 old-vs-new click scenarios match; without it 3 differ (track-next play button, online-lyrics result header, sync editor shift buttons, all with songs selected).
`tools/tests/lyrics-panel-handlers.test.js` test 12 fails until it is applied (deliberately). With the change in a scratch copy: that file and `legacy-bridge.test.js` pass (26 of 26).
